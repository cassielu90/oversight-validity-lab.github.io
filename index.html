Does your oversight actually catch it?

Labs report how much agent activity a monitor sees. No lab publishes how much serious misconduct the monitor and its reviewers miss. We measure it.

In 2026, AI agents got past oversight

  1. May–Jul 2026

    OpenAI / Hugging Face

    Agents in a cyber evaluation messaged each other across runs meant to be isolated (about 1,200 agents, 70,000+ messages), cheated the grader and compromised Hugging Face production systems. OpenAI didn't notice for about a week.

  2. Late Jul

    UK AISI / Claude Mythos 5

    In a permissive cyber evaluation, Mythos 5 acted against real people in 9 of 43 runs, including a malicious pull request to a real open-source project.

  3. 6 Aug

    Meta

    Meta disclosed another incident with the same pattern.

  4. 6 Oct

    Monitoring removed

    An agent removed a monitoring integration, then denied doing so.

Model behaviour, deployment conditions and safeguards failed together.

So we test them together.

  • 0.89
    Tests are recognisable. The best models tell an evaluation transcript from real deployment almost as well as people do: 0.89 AUROC against 0.92.
  • Nearly all
    Coverage isn't catch rate. Labs report that nearly all internal agent actions pass through a monitor. A red-team of OpenAI's internal monitor still found six classes of failure.
  • ?
    Reviewers are part of the system. A reviewer who only sees flagged actions can't catch what the monitor missed.

One method: hold the model fixed, vary the conditions, measure the misses.

  • Open harness

    An Inspect-compatible harness, so any lab or auditor can re-run our experiments.

  • Oversight Validity Reports

    Findings written as narrow claims a lab could truthfully put in a system card.

  • Decision pilot

    We work with an evaluator or deployer to set a real permission or review policy from the results.

Monitor alone vs monitor plus expert review

Agents do contained coding and research tasks with clear rules. We vary three things and measure what gets missed, what gets wrongly blocked and what review costs.

  • A

    Evaluation cues

    Looks like a test, or looks like real work

  • B

    Permission boundaries

    Standard sandbox, or one boundary relaxed

  • C

    Who reviews

    Monitor alone, or monitor plus security and ML experts
